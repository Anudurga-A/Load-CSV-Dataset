# Load a CSV Dataset using Pandas

## 📌 Project Description
This project demonstrates how to load a CSV dataset using the Pandas library in Python and display the first five and last five records.

## 🎯 Objective
To learn how to import real-world tabular data and work with datasets for machine learning workflows.

## 🛠️ Tools and Technologies
- Python
- Pandas
- Jupyter Notebook

## 📊 Dataset
*Dataset Name:* Iris Dataset

*Source:* [Iris CSV Dataset](https://raw.githubusercontent.com/mwaskom/seaborn-data/master/iris.csv)

## 💻 Implementation
1. Import the Pandas library.
2. Load the CSV dataset using pd.read_csv().
3. Display the first five records using df.head().
4. Display the last five records using df.tail().
5. Check the dataset's rows, columns, and missing values.

## 📋 Expected Output
- Successfully loaded CSV dataset.
- First five records displayed.
- Last five records displayed.
- Dataset information and column names displayed.

## 📚 Key Concepts Learned
- CSV file handling
- Pandas DataFrame
- pd.read_csv()
- head() and tail()
- Basic dataset inspection

## ✅ Conclusion
The Iris dataset was successfully loaded using Pandas. The first five and last five records were displayed, providing basic experience in handling tabular data for data analysis and machine learning.
